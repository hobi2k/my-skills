# Python Guide

## 기본 가정

- 가상환경 존재 여부를 먼저 확인합니다.
- 패키지 매니저는 `pip`, `uv`, `poetry` 중 실제 프로젝트 기준으로 씁니다.
- 테스트가 있으면 기본 검증 명령을 함께 적습니다.

## 문서에 자주 넣을 항목

- Python 버전 확인
- venv 활성화 방법
- 의존성 설치 명령
- 실행 엔트리포인트
- pytest 또는 unittest 실행
- `.env` 또는 설정 파일 위치

## 구현 지시 포인트

- 함수 시그니처
- 타입힌트 여부
- 예외 처리 지점
- I/O 경계
- 비동기 함수 여부

## 테스트 지시 포인트

- 정상 케이스
- 경계값
- 예외 발생 케이스
- fixture 필요 여부
