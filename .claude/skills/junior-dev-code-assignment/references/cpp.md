# C++ Guide

## 기본 가정

- 빌드 시스템은 `CMake`, `Make`, `Ninja` 중 실제 프로젝트 기준으로 씁니다.
- 헤더와 소스 파일을 구분해서 설명합니다.

## 문서에 자주 넣을 항목

- 컴파일러 / 표준 버전
- 타깃 바이너리
- 헤더 파일 경로
- 소스 파일 경로
- 빌드 및 실행 명령

## 구현 지시 포인트

- ownership
- const 사용
- 자료구조 선택
- 수명 관리
- 예외 또는 에러 처리 방식

## 테스트 지시 포인트

- 입력 조합
- 경계값
- 메모리/수명 민감 시나리오
- 실행 후 확인 로그
